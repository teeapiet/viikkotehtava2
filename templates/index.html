PYTHON WEB APP

Visitor Counter

This number shows how many times page have been opened and loaded.

{{ visits }}

How this counter and page works?

I used Python and Flask to build this app. Nginx handles the web requests and passes them to my app. MariaDB stores the visit count. If someone opens or load this page, the number goes up.

Restart Test

I restarted server and app started automatically and counter kept its previous value.
